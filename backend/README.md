# Smart Society Complaint And Service Management

A full-stack web application for managing society complaints and service requests.

## Technologies Used

### Frontend
- React.js
- Vite
- Material UI
- Axios
- React Router DOM

### Backend
- Spring Boot
- Spring Data JPA
- Spring Security
- MySQL
- Maven

## Features

- User Registration & Login
- Role-Based Authentication (Admin & Resident)
- Raise Complaint
- Track Complaint Status
- Resident Dashboard
- Admin Dashboard
- Profile Management
- Change Password
- Responsive UI

## Project Structure

```
Smart-Society-Complaint-And-Service-Management/
│
├── frontend/
├── backend/
└── README.md
```

## How to Run

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
mvn spring-boot:run
```

## Database

- MySQL
- Import the `smart_society.sql` file before running the project.
